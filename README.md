# SOBER 資遣費計算與文件產生器

純 HTML／CSS／JavaScript 工具，可部署在 GitHub Pages，也可直接以本機網頁伺服器開啟。員工資料只在瀏覽器記憶體中即時計算，不會儲存或上傳。

## 已完成

- 五家公司資料選擇與自動帶入
- 公司登記地址與實際工作地分開套用
- 法定預告天數、最晚預告日、平均工資、資遣費與預告期間工資試算
- 新制、舊制及新舊制並存
- 依原始表單格式產生資遣通知書、離職證明及非自願離職證明的 A4 PDF 列印頁面
- 資遣通知書分為員工資料、資遣資料、資遣費金額與簽核欄位；簽核欄由左至右為核准、會計、人資、主管、員工。
- 資遣通知書包含離職保密義務、公司財物與資料保護及違反責任說明。
- 平均工資計算明細獨立為第四個 PDF 文件。
- 工資逐月扣除：未足月、事假、遲到分鐘及其他排除工資
- 手機與桌機響應式版面

## 部署

將本資料夾內所有檔案（包含 `vendor` 與 `templates`）上傳到 GitHub Repository 根目錄，GitHub Pages 設為 `main` 與 `/(root)`。

## PDF 匯出

完成計算後按「產生 PDF」，在預覽視窗按「列印／另存 PDF」，於瀏覽器列印目的地選擇「另存為 PDF」。

## 計算方式

- 總年資日數＝離職日－到職日＋1。
- 未滿六個月：日平均工資＝總應領工資÷總年資日數；月平均工資＝日平均工資×30。
- 滿六個月：月平均工資＝六個月總應領工資÷6。
- 應領工資＝原工資－原工資÷30×未足月天數－原工資÷30×事假天數－原工資÷30÷8÷60×遲到分鐘－其他排除工資；未足月、事假、遲到的輸入值及各項扣款小數均無條件捨去。
- 新制畸零年資依實際工作日數分月、日換算：年＋（月＋日÷30）÷12，再乘以二分之一個基數。
- 最終資遣費如有小數，一律無條件進位至整數元；畫面與三份 PDF 使用相同金額。

## 注意

本工具只提供行政作業試算，不代替個案法律判斷。正式金額與文件送出前應由承辦人覆核。
